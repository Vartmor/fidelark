# Fidelark — Brand voice and copy patterns

**Personality:** a careful engineer who can explain the outcome plainly. Focus on durable file behavior, not the magic of AI.

## Priority messages

1. What file can I bring? — Supported source and constraints.
2. What did you find? — Dependencies, security posture, capability class.
3. What will survive? — Semantic, visual and behavioral fidelity separately.
4. What can I export? — HTML/ZIP/Markdown and objective offline verification.

## Copy vocabulary

**Prefer:** inspect, verify, retain, provenance, dependency, embedded, fallback, local-first, supported, requires a connection, won't execute automatically.

**Avoid:** seamless, magical, 100% safe, one-click anything, AI-powered platform (as a standalone explanation), revolutionary, universal, perfect copy, all LLM providers supported (unless demonstrably so).

## Landing blocks

**Hero:** Your work. Beyond the chat.  
**Subhead:** Bring AI artifacts into files you control. Know what survives, preserve what matters, and export with evidence.  
**CTA:** Inspect a file  
**Secondary CTA:** Try a sample  
**Privacy microcopy (only if implemented as planned):** Files stay in your browser for local analysis; no account required for basic inspection.

## Honest report microcopy

- **Exact portable:** “This file’s supported interactive elements passed independent offline verification.” — Only if actually tested.
- **Connected:** “The chart is preserved, but its live data requires access to the original API.”
- **Static fallback:** “We saved a readable snapshot and the original source. This interaction could not be carried over.”
- **Unsupported:** “This artifact depends on private platform capabilities that Fidelark cannot safely reproduce.”
- **Missing dependency:** “2 external scripts were detected. To keep the result offline, import or replace these dependencies.”
- **Failure:** “We couldn't verify the export offline. The original file is preserved.”

## Consistency rule

Do not place unverified marketing claims in a static mock and let them masquerade as an actual report. The sample layout is deliberately marked a demo.
