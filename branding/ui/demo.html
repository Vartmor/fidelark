01 / THE SYSTEM

Confidence in every handoff.

Status is explicit, never a mysterious portability percentage. Each capability has a label, a reason, and a consequence.

● Exact portable

Behavior preserved

Interactive content opens independently as intended, within verified boundaries.

▣ Bundled portable

Dependencies included

The runtime and assets travel with the artifact, without a required online service.

≈ Semantic equivalent

↗ Connected

× Unsupported

Limits made visible
