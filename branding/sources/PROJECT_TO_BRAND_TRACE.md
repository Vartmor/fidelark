# Product strategy → visual identity mapping

| Source principle | Distilled expectation | Brand implementation |
|---|---|---|
| Cross-platform artifact portability | No closed box or proprietary platform claim | Two passing open folds, spatial gap, interchange motif |
| Fidelity classes and evidence | Label behaviors/limits explicitly | Six text+glyph chips with semantic colors, no unexplained percentage |
| Local-first privacy | Control, calm and solidity | Editorial paper, ink, no upload/analytics in mock |
| Security default-deny | Separation and deliberate affordances | Dark audit surfaces, high-contrast borders, no glowing magic |
| Deterministic before AI | Explainable technical system | Monospaced provenance microcopy, stage trace, flat geometry |
| Developer ICP | Works with dev repos and tools | CSS tokens, TypeScript exports, SVG icons, standards-based files |
| Not a general note-taking app | No productivity-notebook identity | Architecture/archive visual language instead of document doodles |

**Supplied sources:** `deep-research-report.md` and `portable_artifact_girisim_master_plani_v1.md`, both dated 2026-11-14. They are the product grounding, not specifications of visual colors or actual logo rights.
